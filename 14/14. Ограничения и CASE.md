# Ограничения и CASE — решение задач

## 1. Добавьте UNIQUE на name

В нашей схеме столбец `name` называется `title`, поэтому используем его:

```sql
CREATE TABLE product (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT UNIQUE,
    price REAL CHECK (price >= 0) DEFAULT 0,
    category_id INTEGER,
    discount REAL,
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

`UNIQUE` запрещает добавлять товары с одинаковым названием.

> Если таблица уже создана, для добавления UNIQUE потребуется пересоздать её. Альтернативно можно создать уникальный индекс:
>
> ```sql
> CREATE UNIQUE INDEX idx_product_title_unique
> ON product(title);
> ```
>
> Индекс не создастся, если в таблице уже есть повторяющиеся названия.

## 2. Выведите товары с меткой «дорого/дёшево»

```sql
SELECT
    title,
    price,
    CASE
        WHEN price > 100 THEN 'дорого'
        ELSE 'дёшево'
    END AS price_category
FROM product;
```

Если цена больше 100 — товар дорогой, иначе — дешёвый.

## 3. Замените NULL в category_id на 0 через COALESCE

```sql
SELECT
    title,
    COALESCE(category_id, 0) AS category_id
FROM product;
```

Если `category_id` равен `NULL`, вместо него будет выведено `0`.

## 4. Используйте NULLIF для избежания деления на 0

```sql
SELECT
    title,
    price,
    1000.0 / NULLIF(price, 0) AS ratio
FROM product;
```

Если `price = 0`, функция `NULLIF` вернёт `NULL`, поэтому деления на ноль не произойдёт.

## 5. Добавьте DEFAULT на price = 0

При создании таблицы:

```sql
CREATE TABLE product (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT UNIQUE,
    price REAL DEFAULT 0 CHECK (price >= 0),
    category_id INTEGER,
    discount REAL,
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

Теперь при добавлении товара без указания цены автоматически будет установлено значение `0`:

```sql
INSERT INTO product (title, category_id)
VALUES ('Новый товар', 1);
```

## 6. CASE с тремя условиями

Цена:
- меньше 50 — «дёшево»;
- от 50 до 100 включительно — «средне»;
- больше 100 — «дорого».

```sql
SELECT
    title,
    price,
    CASE
        WHEN price < 50 THEN 'дёшево'
        WHEN price <= 100 THEN 'средне'
        ELSE 'дорого'
    END AS price_category
FROM product;
```

Условия проверяются по порядку. Если цена меньше 50, возвращается «дёшево». Если первое условие не сработало, проверяется второе.

## 7. COALESCE с двумя столбцами

```sql
SELECT
    title,
    COALESCE(price, 0) + COALESCE(discount, 0) AS total
FROM product;
```

Если `price` или `discount` равны `NULL`, вместо них используется `0`. Затем значения складываются.

## Проверка ограничений

Попробуем добавить товар с отрицательной ценой:

```sql
INSERT INTO product (title, price)
VALUES ('Тестовый товар', -10);
```

Ожидаемый результат: ошибка из-за ограничения `CHECK`.

Попробуем добавить два товара с одинаковым названием:

```sql
INSERT INTO product (title, price)
VALUES ('Телефон', 100);

INSERT INTO product (title, price)
VALUES ('Телефон', 200);
```

Ожидаемый результат: вторая вставка завершится ошибкой из-за `UNIQUE`.
