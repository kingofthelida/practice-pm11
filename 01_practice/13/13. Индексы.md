# Решение задач SQL — Индексы

## 1. Создание индекса по price

Создаём индекс для ускорения поиска товаров по цене.

```sql
CREATE INDEX idx_product_price
ON product(price);
```

Проверяем работу индекса:

```sql
EXPLAIN QUERY PLAN
SELECT * FROM product
WHERE price > 100;
```

## 2. Создание индекса по name

Создаём индекс для ускорения поиска товаров по названию.

```sql
CREATE INDEX idx_product_name
ON product(title);
```

Проверяем индекс:

```sql
EXPLAIN QUERY PLAN
SELECT * FROM product
WHERE title = 'Хлеб';
```

## 3. Создание составного индекса по category_id и price

Создаём составной индекс, который ускоряет поиск товаров по категории и цене.

```sql
CREATE INDEX idx_product_cat_price
ON product(category_id, price);
```

Проверяем:

```sql
EXPLAIN QUERY PLAN
SELECT * FROM product
WHERE category_id = 1
AND price > 100;
```

## 4. Проверка плана запроса через EXPLAIN QUERY PLAN

Проверяем, использует ли SQLite созданные индексы.

```sql
EXPLAIN QUERY PLAN
SELECT * FROM product
WHERE price > 100;
```

Проверяем поиск по названию:

```sql
EXPLAIN QUERY PLAN
SELECT * FROM product
WHERE title = 'Хлеб';
```

**Возможные результаты:**

- SCAN product — последовательное сканирование таблицы.
- SEARCH product USING INDEX — поиск с использованием индекса.

Если SQLite использует индекс, поиск выполняется без полного просмотра таблицы.

## 5. Удаление одного индекса

Удаляем индекс по цене.

```sql
DROP INDEX idx_product_price;
```

Проверяем план запроса повторно:

```sql
EXPLAIN QUERY PLAN
SELECT * FROM product
WHERE price > 100;
```

После удаления индекса SQLite может использовать другой подходящий индекс или выполнить полное сканирование таблицы.

## 6. Создание уникального индекса на name

Создаём уникальный индекс, который запрещает добавление товаров с одинаковым названием.

```sql
CREATE UNIQUE INDEX idx_product_unique_name
ON product(title);
```

Проверяем работу ограничения:

```sql
INSERT INTO product (title, price, category_id)
VALUES ('Хлеб', 50, 1);
```

**Ожидаемый результат:** ошибка, если товар с названием «Хлеб» уже существует.

Пример ошибки:

```text
UNIQUE constraint failed: product.title
```

## 7. Создание индекса на два столбца (name, category_id)

Создаём составной индекс по названию товара и категории.

```sql
CREATE INDEX idx_product_name_category
ON product(title, category_id);
```

Проверяем работу индекса:

```sql
EXPLAIN QUERY PLAN
SELECT * FROM product
WHERE title = 'Хлеб'
AND category_id = 1;
```

Индекс помогает ускорить поиск по двум столбцам одновременно.

## 8. Сравнение времени выполнения запроса с индексом и без него

Сначала удаляем индекс по цене, если он существует:

```sql
DROP INDEX IF EXISTS idx_product_price;
```

В DB Browser for SQLite выполняем запрос:

```sql
SELECT * FROM product
WHERE price > 100;
```

Запоминаем время выполнения запроса.

Теперь создаём индекс:

```sql
CREATE INDEX idx_product_price
ON product(price);
```

Повторяем тот же запрос:

```sql
SELECT * FROM product
WHERE price > 100;
```

Сравниваем время выполнения.

Для измерения времени в консольной версии SQLite можно использовать команду:

```text
.timer on
```

После этого выполняем запросы и сравниваем показанное время.

**Результат:** индекс может ускорить поиск товаров по цене, особенно если таблица содержит большое количество записей.

## Итоговая проверка

Посмотреть список индексов таблицы:

```sql
PRAGMA index_list(product);
```

Посмотреть структуру таблицы:

```sql
PRAGMA table_info(product);
```

Проверить план запроса:

```sql
EXPLAIN QUERY PLAN
SELECT * FROM product
WHERE category_id = 1
AND price > 100;
```
