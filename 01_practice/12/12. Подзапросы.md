# Подзапросы SQL — решения заданий

## 1. Товары дороже средней цены

```sql
SELECT *
FROM product
WHERE price > (
    SELECT AVG(price)
    FROM product
);
```

## 2. Товары из категории «Еда»

```sql
SELECT *
FROM product
WHERE category_id = (
    SELECT id
    FROM category
    WHERE name = 'Еда'
);
```

## 3. Категории, в которых есть товары (`EXISTS`)

```sql
SELECT *
FROM category c
WHERE EXISTS (
    SELECT 1
    FROM product p
    WHERE p.category_id = c.id
);
```

## 4. Категории без товаров (`NOT EXISTS`)

```sql
SELECT *
FROM category c
WHERE NOT EXISTS (
    SELECT 1
    FROM product p
    WHERE p.category_id = c.id
);
```

## 5. Товар с максимальной ценой

```sql
SELECT *
FROM product
WHERE price = (
    SELECT MAX(price)
    FROM product
);
```

## 6. Товары дороже средней цены по своей категории

```sql
SELECT *
FROM product p
WHERE p.price > (
    SELECT AVG(p2.price)
    FROM product p2
    WHERE p2.category_id = p.category_id
);
```

## 7. Товары дороже максимальной цены в категории 2

```sql
SELECT *
FROM product
WHERE price > (
    SELECT MAX(price)
    FROM product
    WHERE category_id = 2
);
```

## 8. Категории, у которых средняя цена товаров больше 100

```sql
SELECT c.*
FROM category c
WHERE (
    SELECT AVG(p.price)
    FROM product p
    WHERE p.category_id = c.id
) > 100;
```

## 9. Задача на поиск ошибки

### Исходный запрос

```sql
SELECT *
FROM product
WHERE price > (
    SELECT price
    FROM product
    WHERE category_id = 1
);
```

### Исправленный запрос

```sql
SELECT *
FROM product

    SELECT MAX(price)

```

## 10. Задача на предсказание результата

### Запрос

```sql
SELECT *
FROM category c
WHERE NOT EXISTS (
    SELECT 1
    FROM product p
    WHERE p.category_id = c.id
);
```

### Данные

- Категории: `1`, `2`.
- Товары: только в категории `1`.

### Результат

| id категории | Результат |
|---|---|
| 1 | Не выводится |
| 2 | Выводится |

**Ответ:** будет выведена только категория `2`, поскольку в ней нет товаров.

## 11. Продвинутое задание: два CTE

**Условие:** написать запрос с двумя CTE: один вычисляет среднюю цену по категории, второй — максимальную цену.

```sql
WITH avg_prices AS (
    SELECT
        category_id,
        AVG(price) AS avg_price
    FROM product
    GROUP BY category_id
),
max_prices AS (
    SELECT
        category_id,
        MAX(price) AS max_price
    FROM product
    GROUP BY category_id
)
SELECT
    p.*,
    a.avg_price,
    m.max_price
FROM product p
JOIN avg_prices a
    ON p.category_id = a.category_id
JOIN max_prices m
    ON p.category_id = m.category_id;
```в
