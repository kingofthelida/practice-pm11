# Решение задач SQL — Импорт CSV

## 1. Подготовка CSV с 5 товарами

Создаём файл `products.csv` со следующими данными:

```csv
name,price,category_id
Хлеб,40,1
Мыло,80,2
Молоко,60,1
Наушники,3500,1
Книга,1200,2
```

## 2. Создание временной таблицы

Создаём временную таблицу, в которой все столбцы имеют тип TEXT.

```sql
CREATE TABLE tmp_product (
    name TEXT,
    price TEXT,
    category_id TEXT
);
```

## 3. Импорт CSV через DB Browser

Выполняем следующие действия:

1. Открываем DB Browser for SQLite.
2. Выбираем File → Import → Table from CSV file.
3. Выбираем файл `products.csv`.
4. Указываем имя таблицы `tmp_product`.
5. Устанавливаем разделитель — запятая.
6. Ставим галочку First row contains column names.
7. Нажимаем OK.

## 4. Преобразование типов и перенос данных в product

Переносим данные из временной таблицы в основную таблицу `product`.

```sql
INSERT INTO product (title, price, category_id)
SELECT
    TRIM(name),
    CAST(price AS REAL),
    CAST(category_id AS INTEGER)
FROM tmp_product;
```

## 5. Проверка результата

Проверяем, что все товары успешно перенесены.

```sql
SELECT * FROM product;
```

Проверяем количество записей:

```sql
SELECT COUNT(*) AS total_products
FROM product;
```

Ожидаемый результат: 5 записей.

## 6. Удаление временной таблицы

После успешного импорта удаляем временную таблицу.

```sql
DROP TABLE tmp_product;
```

## 7. Подготовка CSV с грязными данными и очистка через TRIM и LOWER

Создаём файл `dirty_products.csv`:

```csv
name,price,category_id
"  ХЛЕБ  ",40,1
"  Мыло  ",80,2
"  МОЛОКО  ",60,1
"  НАУШНИКИ  ",3500,1
"  Книга  ",1200,2
```

Создаём временную таблицу:

```sql
CREATE TABLE tmp_dirty_product (
    name TEXT,
    price TEXT,
    category_id TEXT
);
```

Импортируем CSV через DB Browser в таблицу `tmp_dirty_product`.

Очищаем данные и переносим их в основную таблицу:

```sql
INSERT INTO product (title, price, category_id)
SELECT
    LOWER(TRIM(name)),
    CAST(TRIM(price) AS REAL),
    CAST(TRIM(category_id) AS INTEGER)
FROM tmp_dirty_product;
```

Проверяем результат:

```sql
SELECT * FROM product;
```

После проверки удаляем временную таблицу:

```sql
DROP TABLE tmp_dirty_product;
```

## 9. Импорт CSV с датами DD.MM.YYYY и преобразование в YYYY-MM-DD

Создаём файл `products_dates.csv`:

```csv
name,price,category_id,created
Хлеб,40,1,15.10.2026
Мыло,80,2,20.10.2026
Молоко,60,1,25.10.2026
```

Создаём временную таблицу:

```sql
CREATE TABLE tmp_dates (
    name TEXT,
    price TEXT,
    category_id TEXT,
    created TEXT
);
```

Импортируем CSV через DB Browser.

Переносим данные с преобразованием даты:

```sql
INSERT INTO product (title, price, category_id, created)
SELECT
    TRIM(name),
    CAST(price AS REAL),
    CAST(category_id AS INTEGER),
    SUBSTR(created, 7, 4) || '-' ||
    SUBSTR(created, 4, 2) || '-' ||
    SUBSTR(created, 1, 2)
FROM tmp_dates;
```

Проверяем результат:

```sql
SELECT title, price, created
FROM product;
```

Ожидаемый формат даты: YYYY-MM-DD.

Удаляем временную таблицу:

```sql
DROP TABLE tmp_dates;
```

## 10. Задача со звёздочкой — поиск некорректных значений

Напишем SQL-запрос, который находит строки с отрицательной ценой, пустыми значениями или NULL.

```sql
SELECT *
FROM tmp_product
WHERE
    price IS NULL
    OR TRIM(price) = ''
    OR CAST(price AS REAL) < 0
    OR name IS NULL
    OR TRIM(name) = ''
    OR category_id IS NULL
    OR TRIM(category_id) = '';
```

Запрос позволяет найти некорректные данные до их переноса в основную таблицу.

## 11. Задача на поиск ошибки

**Условие:**

Студент импортировал CSV, но в таблице оказалось 100 строк вместо 50. Что могло произойти?

**Ответ:**

Возможные причины:

1. CSV-файл импортировали два раза.
2. При повторном импорте данные добавились к уже существующим.
3. Перед повторным импортом не очистили временную таблицу.
4. Не проверили количество записей перед переносом данных.

Чтобы проверить количество записей:

```sql
SELECT COUNT(*) FROM tmp_product;
```

Чтобы очистить таблицу перед повторным импортом:

```sql
DELETE FROM tmp_product;
```

## 12. Задача на предсказание результата

**Условие:**

Дан CSV-файл:

```csv
name,price
Хлеб,40
Мыло,80
```

Что произойдёт при импорте в таблицу с типами TEXT и REAL?

**Ответ:**

1. Столбец `name` получит значения «Хлеб» и «Мыло».
2. Столбец `price` получит значения 40 и 80.
3. SQLite сохранит числовые значения в столбце REAL как числа с плавающей точкой.
4. Будут добавлены две записи.
