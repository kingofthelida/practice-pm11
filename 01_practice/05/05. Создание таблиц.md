# Решение задач SQL

## 1\. Создание таблицы category

```sql
CREATE TABLE category (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE
);
```

## 2\. Создание таблицы product

```sql
CREATE TABLE product (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    price REAL NOT NULL,
    category_id INTEGER NOT NULL,
    FOREIGN KEY (category_id) REFERENCES category(id)
);
```

## 3\. Добавление CHECK на цену

```sql
ALTER TABLE product
ADD CONSTRAINT chk_product_price
CHECK (price > 0);
```

&nbsp;

```sql
CREATE TABLE product (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    price REAL NOT NULL CHECK (price > 0),
    category_id INTEGER NOT NULL,
    FOREIGN KEY (category_id) REFERENCES category(id)
);
```

4\. Добавление по две записи в каждую таблицу

Добавление категорий:

```sql
INSERT INTO category (name)
VALUES
    ('Электроника'),
    ('Книги');
```

Добавление товаров:

```sql
INSERT INTO product (name, price, category_id)
VALUES
    ('Наушники', 3500.00, 1),
    ('SQL для начинающих', 1200.00, 2);
```

## 5\. Проверка ограничений

Проверка UNIQUE:

```sql
INSERT INTO category (name)
VALUES ('Электроника');
```

Проверка CHECK:

```sql
INSERT INTO product (name, price, category_id)
VALUES ('Тестовый товар', -100, 1);
```

Проверка FOREIGN KEY:

```sql
INSERT INTO product (name, price, category_id)
VALUES ('Неизвестный товар', 500, 999);
```

## 6\. Создание таблицы supplier

```sql
CREATE TABLE supplier (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    phone TEXT NOT NULL UNIQUE,
    email TEXT NOT NULL UNIQUE
);
```

Добавление двух записей:

```sql
INSERT INTO supplier (name, phone, email)
VALUES
    ('Поставщик А', '+7-700-111-22-33', 'a@example.com'),
    ('Поставщик Б', '+7-700-444-55-66', 'b@example.com');
```

## 7\. Создание таблицы shipment

```sql
CREATE TABLE shipment (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    product_id INTEGER NOT NULL,
    supplier_id INTEGER NOT NULL,
    quantity INTEGER NOT NULL CHECK (quantity > 0),
    date DATE NOT NULL DEFAULT CURRENT_DATE,

    FOREIGN KEY (product_id) REFERENCES product(id),
    FOREIGN KEY (supplier_id) REFERENCES supplier(id)
);
```

Добавление двух записей:

```sql
INSERT INTO shipment (product_id, supplier_id, quantity)
VALUES
    (1, 1, 10),
    (2, 2, 25);
```

Поле date автоматически заполняется текущей датой.

## 8\. Создание таблицы с составным UNIQUE

```sql
CREATE TABLE product_supplier (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    product_id INTEGER NOT NULL,
    supplier_id INTEGER NOT NULL,

    FOREIGN KEY (product_id) REFERENCES product(id),
    FOREIGN KEY (supplier_id) REFERENCES supplier(id),

    UNIQUE (product_id, supplier_id)
);
```

Добавление двух записей:

```sql
INSERT INTO product_supplier (product_id, supplier_id)
VALUES
    (1, 1),
    (2, 2);
```

Проверка составного UNIQUE:

```sql
INSERT INTO product_supplier (product_id, supplier_id)
VALUES (1, 1);
```

Ожидаемый результат: ошибка, так как такая комбинация уже существует.

## Итоговая проверка таблиц

```sql
SELECT * FROM category;

SELECT * FROM supplier;
SELECT * FROM shipment;
SELECT * FROM product_supplier;
```

## Включение внешних ключей в SQLite

SQLite по умолчанию может не проверять внешние ключи. Поэтому перед выполнением скрипта необходимо включить их проверку:

```sql
PRAGMA foreign_keys = ON;
```

## Заключение

В результате выполнения работы созданы пять таблиц:

1. category — категории товаров;  
2. product — товары;  
3. supplier — поставщики;  
4. shipment — поставки товаров;  
5. product\_supplier — связь товаров с поставщиками.

Использованы следующие ограничения SQL:

- PRIMARY KEY — первичный ключ;  
- FOREIGN KEY — внешний ключ;  
- UNIQUE — уникальность значений;  
- CHECK — проверка условий;  
- DEFAULT — значение по умолчанию;  
- NOT NULL — запрет пустых значений.

**Результат:** все 8 заданий выполнены с использованием SQLite.
