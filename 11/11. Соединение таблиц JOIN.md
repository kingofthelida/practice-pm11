# Решение задач SQL — Соединение таблиц JOIN

## 1. Вывод товаров с названиями категорий (INNER JOIN)

Соединяем таблицы товаров и категорий. Выводятся только товары, у которых есть соответствующая категория.

```sql
SELECT
    p.title,
    c.name AS category
FROM product p
INNER JOIN categories c
    ON p.category_id = c.id;
```

## 2. Вывод всех категорий, даже без товаров (LEFT JOIN)

Выводим все категории, включая те, в которых нет товаров.

```sql
SELECT
    c.name AS category,
    p.title AS product
FROM categories c
LEFT JOIN product p
    ON c.id = p.category_id;
```

Если в категории нет товаров, в столбце product будет NULL.

## 3. Вывод товаров без категории (LEFT JOIN + IS NULL)

Находим товары, у которых отсутствует категория.

```sql
SELECT
    p.title,
    p.category_id
FROM product p
LEFT JOIN categories c
    ON p.category_id = c.id
WHERE c.id IS NULL;
```

Результат: товары без соответствующей категории.

## 4. Количество товаров в каждой категории

Используем LEFT JOIN и COUNT(), чтобы вывести количество товаров, включая категории без товаров.

```sql
SELECT
    c.name AS category,
    COUNT(p.id) AS product_count
FROM categories c
LEFT JOIN product p
    ON c.id = p.category_id
GROUP BY c.id, c.name;
```

Результат: название каждой категории и количество товаров в ней.

## 5. Соединение товаров и категорий через FULL JOIN

FULL JOIN возвращает все строки из обеих таблиц, даже если совпадения нет.

```sql
SELECT
    p.title AS product,
    c.name AS category
FROM product p
FULL JOIN categories c
    ON p.category_id = c.id;
```

Если товар не имеет категории или категория не имеет товаров, соответствующие поля будут содержать NULL.

**Примечание:** FULL JOIN поддерживается в SQLite начиная с версии 3.39.0.

## 6. Вывод категорий без товаров

Используем LEFT JOIN и IS NULL.

```sql
SELECT
    c.id,
    c.name
FROM categories c
LEFT JOIN product p
    ON c.id = p.category_id
WHERE p.id IS NULL;
```

Результат: категории, в которых нет ни одного товара.

## 7. Соединение трёх таблиц: товар, категория, поставщик

В нашей структуре связь товара с поставщиком реализована через промежуточную таблицу product_supplier.

```sql
SELECT
    p.title AS product,
    c.name AS category,
    s.name AS supplier
FROM product p
INNER JOIN categories c
    ON p.category_id = c.id
INNER JOIN product_supplier ps
    ON p.id = ps.product_id
INNER JOIN supplier s
    ON ps.supplier_id = s.id;
```

Результат: название товара, его категория и поставщик.

## 8. Вывод товаров, у которых категория начинается на «Е»

Используем LIKE для поиска категорий, название которых начинается с буквы «Е».

```sql
SELECT
    p.title AS product,
    c.name AS category
FROM product p
INNER JOIN categories c
    ON p.category_id = c.id
WHERE c.name LIKE 'Е%';
```

Результат: товары из категорий, название которых начинается на «Е».

## 9. Задача со звёздочкой — Self-join

Выводим пары товаров, которые находятся в одной категории, но имеют разные ID.

```sql
SELECT
    p1.title AS product_1,
    p2.title AS product_2,
    p1.category_id
FROM product p1
INNER JOIN product p2
    ON p1.category_id = p2.category_id
WHERE p1.id < p2.id;
```

Объяснение:

- p1 и p2 — две ссылки на одну таблицу product.
- Соединяем товары с одинаковым category_id.
- Условие p1.id < p2.id исключает совпадение товара с самим собой и повторение одинаковых пар.

## 10. Задача на поиск ошибки

Дан SQL-код:

```sql
SELECT p.title, c.name
FROM product p
JOIN categories c;
```

**Что не так?**

Ответ:

В запросе отсутствует условие ON, которое определяет связь между таблицами.

Из-за этого получается декартово произведение: каждая строка первой таблицы соединяется с каждой строкой второй таблицы.

Правильный вариант:

```sql
SELECT
    p.title,
    c.name
FROM product p
JOIN categories c
    ON p.category_id = c.id;
```

## 11. Задача на предсказание результата

```sql
SELECT
    p.title,
    c.name
FROM product p
LEFT JOIN categories c
    ON p.category_id = c.id;
```

**Ответ:**

LEFT JOIN возвращает все товары из левой таблицы product.

Результат:

- Хлеб имеет category_id = 1, поэтому находит категорию «Еда».
- Сыр имеет category_id = NULL, поэтому категория не находится.
- Благодаря LEFT JOIN товар «Сыр» всё равно отображается.

## 12. Продвинутый случай — замена RIGHT JOIN на LEFT JOIN

RIGHT JOIN можно переписать через LEFT JOIN, поменяв таблицы местами.

Исходный запрос:

```sql
SELECT
    p.title,
    c.name AS category
FROM product p
RIGHT JOIN categories c
    ON p.category_id = c.id;
```

Запрос через LEFT JOIN:

```sql
SELECT
    p.title,
    c.name AS category
FROM categories c
LEFT JOIN product p
    ON c.id = p.category_id;
```

Результат будет одинаковым: выводятся все категории, даже если в них нет товаров.
