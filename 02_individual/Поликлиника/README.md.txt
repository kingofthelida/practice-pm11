# База данных «Поликлиника»

## Описание проекта

Проект представляет собой реляционную базу данных для автоматизации работы поликлиники.

## Используемые технологии

- SQLite
- DB Browser for SQLite
- SQL
- CSV
- Mermaid

## Структура проекта

- `polyclinic.db` — файл базы данных.
- `csv/` — исходные CSV-файлы с данными.
- `sql/` — SQL-скрипты создания таблиц, индексов и запросов.
- `docs/` — отчёт и ER-диаграмма.
- `screenshots/` — скриншоты результатов работы.

## Сущности

База данных содержит 8 таблиц:

1. Specialties
2. Patients
3. Doctors
4. Rooms
5. Appointments
6. Diagnoses
7. Appointment_Diagnoses
8. Prescriptions

## Реализованные возможности

- Хранение информации о пациентах и врачах.
- Учёт специальностей и кабинетов.
- Регистрация приёмов.
- Хранение диагнозов и назначений.
- Выполнение SQL-запросов и получение статистики.
- Индексация для ускорения поиска.
