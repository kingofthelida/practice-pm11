
# Практическая работа: работа с базой данных SQLite

## 1. Создайте БД practice.db

В SQLite база данных создаётся автоматически при подключении к файлу.

В DB Browser for SQLite:
1. Откройте программу.
2. Выберите File → New Database.
3. Укажите имя `practice.db`.
4. Сохраните файл.

Либо через терминал:

```bash
sqlite3 practice.db
```

## 2. Создайте таблицу student

Поля:
- `id` — идентификатор студента;
- `full_name` — ФИО;
- `birth_date` — дата рождения;
- `average_grade` — средний балл.

```sql
CREATE TABLE student (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    full_name TEXT NOT NULL,
    birth_date TEXT,
    average_grade REAL
);
```

## 3. Вставьте 3 записи

```sql
INSERT INTO student (full_name, birth_date, average_grade)
VALUES
    ('Иванов Иван Иванович', '2004-05-12', 4.5),
    ('Петров Пётр Сергеевич', '2003-11-20', 3.8),
    ('Сидорова Анна Дмитриевна', '2005-02-15', 4.9);
```

## 4. Сохраните изменения (Write Changes)

В DB Browser for SQLite нажмите кнопку **Write Changes** на панели инструментов.

Она сохраняет выполненные изменения в файл базы данных.

Если вы работаете через SQLite CLI, изменения обычно сохраняются автоматически после выполнения SQL-команд, если транзакция не была открыта вручную.

## 5. Выведите все записи

```sql
SELECT * FROM student;
```

## 6. Создайте таблицу teacher

Поля:
- `id` — идентификатор преподавателя;
- `full_name` — ФИО;
- `subject` — предмет;
- `experience` — стаж работы в годах.

```sql
CREATE TABLE teacher (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    full_name TEXT NOT NULL,
    subject TEXT NOT NULL,
    experience INTEGER
);
```

## 7. Вставьте 5 записей в teacher и выведите преподавателей со стажем > 5 лет

Добавление записей:

```sql
INSERT INTO teacher (full_name, subject, experience)
VALUES
    ('Смирнов Алексей Викторович', 'Математика', 10),
    ('Кузнецова Мария Ивановна', 'История', 3),
    ('Васильев Дмитрий Олегович', 'Информатика', 7),
    ('Попова Елена Сергеевна', 'Физика', 12),
    ('Морозов Андрей Петрович', 'Английский язык', 2);
```

Вывод преподавателей со стажем больше 5 лет:

```sql
SELECT *
FROM teacher
WHERE experience > 5;
```

В результате должны отобразиться:
- Смирнов Алексей Викторович — 10 лет;
- Васильев Дмитрий Олегович — 7 лет;
- Попова Елена Сергеевна — 12 лет.

## 8. Создайте таблицу с полем типа BLOB и объясните, зачем оно нужно

```sql
CREATE TABLE student_files (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER,
    file_name TEXT,
    file_data BLOB,
    FOREIGN KEY (student_id) REFERENCES student(id)
);
```

**Что такое BLOB?**

BLOB (Binary Large Object) — тип данных для хранения двоичной информации.

Он подходит для хранения:
- фотографий;
- изображений;
- PDF-документов;
- аудиофайлов;
- других бинарных файлов.

Например, в таблице `student_files` можно хранить фотографию студента или его документы.

`file_name` хранит название файла, а `file_data` — непосредственно его двоичное содержимое.
