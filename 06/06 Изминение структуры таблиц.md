# Решение задач SQL

## 1. Добавление столбца description TEXT

```sql
ALTER TABLE product
ADD COLUMN description TEXT;
```

## 2. Переименование столбца name в title

```sql
ALTER TABLE product
RENAME COLUMN name TO title;
```

## 3. Удаление столбца description

```sql
ALTER TABLE product
DROP COLUMN description;
```

## 4. Переименование таблицы category → categories

```sql
ALTER TABLE category
RENAME TO categories;
```

## 5. Удаление таблицы product

```sql
DROP TABLE product;
```

## 6. Добавление столбца created TEXT DEFAULT (date('now'))

Создаём таблицу product с новым столбцом created:

```sql
CREATE TABLE product (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    price REAL NOT NULL CHECK (price > 0),
    category_id INTEGER NOT NULL,
    created TEXT DEFAULT (date('now')),
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

## 7. Пересоздание таблицы product с новым типом столбца

Создаём новую таблицу:

```sql
CREATE TABLE product_new (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    price REAL NOT NULL,
    category_id INTEGER NOT NULL,
    created TEXT DEFAULT (date('now')),
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

Переносим данные:

```sql
INSERT INTO product_new (id, title, price, category_id, created)
SELECT id, title, CAST(price AS REAL), category_id, created
FROM product;
```

Удаляем старую таблицу:

```sql
DROP TABLE product;
```

Переименовываем новую таблицу:

```sql
ALTER TABLE product_new
RENAME TO product;
```

## 8. Пересоздание таблицы с новым ограничением CHECK

Создаём новую таблицу с дополнительным ограничением: название товара должно содержать минимум два символа, а цена должна быть больше нуля.

```sql
CREATE TABLE product_new (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL CHECK (length(title) >= 2),
    price REAL NOT NULL CHECK (price > 0),
    category_id INTEGER NOT NULL,
    created TEXT DEFAULT (date('now')),
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

Переносим данные:

```sql
INSERT INTO product_new (id, title, price, category_id, created)
SELECT id, title, price, category_id, created
FROM product;
```

Удаляем старую таблицу:

```sql
DROP TABLE product;
```

Переименовываем новую таблицу:

```sql
ALTER TABLE product_new
RENAME TO product;
```

## Итоговая проверка

Проверяем структуру таблицы:

```sql
PRAGMA table_info(product);
```

Проверяем данные:

```sql
SELECT * FROM product;
```

Проверяем внешние ключи:

```sql
PRAGMA foreign_key_list(product);
```

Проверяем ограничение CHECK:

```sql
INSERT INTO product (title, price, category_id)
VALUES ('A', 100, 1);
```

Ожидаемый результат: ошибка, поскольку название содержит меньше двух символов.

## Заключение

В ходе выполнения работы были изучены команды изменения структуры базы данных SQLite:

- ALTER TABLE ADD COLUMN — добавление столбца;
- ALTER TABLE RENAME COLUMN — переименование столбца;
- ALTER TABLE DROP COLUMN — удаление столбца;
- ALTER TABLE RENAME TO — переименование таблицы;
- DROP TABLE — удаление таблицы;
- CREATE TABLE — создание таблицы;
- INSERT INTO SELECT — перенос данных;
- CAST() — преобразование типа данных.

**Результат:** все 8 заданий выполнены. Изменена структура таблиц, добавлены и удалены столбцы, переименованы таблицы и реализованы новые ограничения.
